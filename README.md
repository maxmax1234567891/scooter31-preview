# Скутер31: макет шин и камер

Демонстрационная витрина для просмотра с телефона и согласования с сотрудниками. Заказы и оплата не подключены. Цены демонстрационные, актуальность подтверждает магазин. Изображения включают реконструкции на согласование.

В репозитории только публичные файлы витрины. Реальные количества остатков, показатели продаж, выгрузки 1С и внутренние отчеты исключены.

## Изменения
Редактируйте файлы, создавайте коммит и отправляйте в main. GitHub Pages обновляет витрину из корня main. Для обсуждения используйте Issues или комментарии к коммитам/PR.

## Локальный просмотр
python -m http.server 8774

## Публикация
Settings → Pages → Deploy from a branch → main → /(root).
